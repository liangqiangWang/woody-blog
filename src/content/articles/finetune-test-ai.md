> 之前搭建过许多 AI 应用，通常只要涉及到业务知识，都是基于知识库（RAG）实现，基本能满足需求。但一直好奇模型微调后的效果会不会比知识库更好，所以本文尝试微调了一个**掌握自动化测试框架的 LLM**。

最近分别尝试了在 MacOS 本地用 MLX 框架微调，以及使用`硅基流动`的微调服务，都是基于 Qwen 模型微调。对比发现硅基流动的微调上手相当简单，效果也还比较明显，下面主要介绍这种方式。

本次基于 Qwen-7B-instruct 微调，共几十条训练数据，花费不到2元。

## 一、模型微调的价值

大语言模型通过预训练获得了强大的通用能力，基本涵盖了互联网上全部公开数据。但是缺乏一些专业领域/私有数据的知识。通过微调，可以在保持模型通用能力的基础上，针对性地优化特定任务表现。

核心价值：

- 提高性能：微调可以显著提高模型在特定任务上的性能。
- 减少训练时间：相比于从头开始训练模型，微调通常需要较少的训练时间和计算资源。
- 适应特定领域：微调可以帮助模型更好地适应特定领域的数据和任务。

## 二、微调过程

> 数据质量直接决定微调最终的效果，所以应当花费最多的时间在数据准备上。

### 2.1 环境准备

由于微调直接采用硅基流动的服务，所以省去了环境搭建，也不需要准备硬件资源。只需要准备两样：

1. 开源的大模型数据集创建工具：EasyDataset，直接下载安装即可。
2. 准备一个通用的大模型 key。因为 EasyDataset 还是需要 AI 协助做数据拆分、清洗。否则人工构造数据成本太高。

### 2.2 数据准备

为了方便演示，我让 AI 帮我虚构了一个自动化框架，并生成了对应的 API 文档。下面就以这份 API 文档作为微调训练原始数据。

#### 微调需要的数据结构

主流的微调主要有Alpaca和ShareGPT格式。硅基流动上需要的是SHareGPT 格式。

Alpaca风格：

```json
{
  "instruction": "人类指令（必填）",
  "input": "人类输入（选填）",
  "output": "模型回答（必填）",
  "system": "系统提示词（选填）"
}
{
  "instruction": "第二个指令",
  "input": "",
  "output": "第二个回答",
  "system": "系统提示词"
}
```

ShareGPT风格：

```json
{
  "messages": [
    {
      "role": "system",
      "content": "你是客服助手"
    },
    {
      "role": "user",
      "content": "如何修改收货地址？"
    },
    {
      "role": "assistant",
      "content": "您可以按以下步骤修改：\n1. 进入订单详情\n2. 点击'修改地址'\n3. 输入新地址信息\n4. 保存修改"
    }
  ]
}
{
  "messages": [
    {
      "role": "system",
      "content": "你是客服助手"
    },
    {
      "role": "user",
      "content": "如何指定收获时间"
    },
    {
      "role": "assistant",
      "content": "您可以按以下步骤修改：\n1. 进入订单详情\n2. 点击'修改送货时间'\n3. 输入新收获时间\n4. 保存修改"
    }
  ]
}
```

本质上只是 json 字段差异，所以数据准备的核心是围绕原始数据`准备 q-a 问答对`。而数据格式， EasyDataset 会帮我们搞定。

#### 使用 EasyDataset 构造问题对

将 API 文档直接上传到 EasyDataset中，会自动分割成文本块。分割的文本块最好人工矫正一下，确保每段都是相对完整、没有截断，因为可能影响后续生成`q-a问答对`的质量。

![文本分块](/images/articles/finetune-test-ai/finetune-test-ai-2.png)

接下来通过【自动提取问题】就能针对每段生成一些问题。

**注意：**为了保证生成的问题质量，建议根据内容特点修改内置提示词。比如我准备的案例是自动化框架API文档，所以准备的问题尽量围绕 API命名、参数、用法更合适。

对于生成的问题，最好是人工做一遍检查校对，避免一些低质量的问题。

![问题检查校对](/images/articles/finetune-test-ai/finetune-test-ai-3.png)

#### 生成数据集

下一步就是针对这些问题构造数据集。AI 会根据问题，结合问题关联的文本块，生成答案。 （可以通过优化内置提示词提升答案质量，不做赘述）

![生成数据集](/images/articles/finetune-test-ai/finetune-test-ai-4.png)

#### 导出数据集

EastDataset 提供了多种数据格式，甚至可以自定义。 本次选择平台需要的格式即可。

![导出数据集](/images/articles/finetune-test-ai/finetune-test-ai-5.png)

### 2.3 开始微调

硅基流动提供了傻瓜式的微调方式，只需要选择模型、上传数据、选择参数即可。官方文档中有详细介绍。

#### 创建微调任务

目前平台只提供了 Qwen 模型。不同大小模型训练单价格不同，因为消耗算力差异较大。另外训练数据量也直接影响最终花费。

微调的参数说明可以参考官方文档，默认的参数就能应付大部分场景。

![创建微调任务](/images/articles/finetune-test-ai/finetune-test-ai-6.png)

提交任务后只需等待就好。

因为演示的训练数据量实在太小，模型也小，几乎没花钱。

![训练花费](/images/articles/finetune-test-ai/finetune-test-ai-7.png)

#### 微调验证

训练结束后就能得到微调后模型id，可以通过官方的 API 直接调用。

在文本对话窗口，也可以直接选择到微调后的模型。所以可以做一个效果对比。

![效果对比](/images/articles/finetune-test-ai/finetune-test-ai-8.png)

很明显，微调过后的模型是掌握了训练数据的。相关的问题都能答到点上，但是在训练数据之外的问题还是得不到期望结果。毕竟只有几十条训练数据。

### 2.4 关于训练成本

训练成本主要包含两部分：

- EasyDataset 制作数据集会消耗一些 Token 资源。实测 Doubao-1.5-pro-256k 模型，生成 500+ 问答数据也只花费了2元不到。
- 微调费用取决于模型大小和训练数据量。之前尝试过 32B 模型、500+数据，实际花费也不到3块。（新注册账号还赠送了15元，几乎就是白嫖了）

## 三、写在后面

本次只是一次不严谨的微调实践，也未深入研究各种微调框架和参数，主要是想了解微调的过程以及效果。

### 感受

- **微调的成本越来越低**现在微调一个模型的门槛和成本已经非常低，甚至不用写代码，就能快速训练一个"可用"的私有模型。
- **数据质量是微调的核心**如果能提升数据质量和总量，我相信微调模型是可以在很多场景下替代知识库的。
- **微调可能没有想象中那么全能**绝大部分场景下，用好上下文工程，效果可能比用少量数据微调效果要好，而且更灵活。
