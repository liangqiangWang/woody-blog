ClaudeCode 爆火之后，相似的 CLI 工具就层出不穷。

**好用是真的好用，贵也是真的贵。**

很多国产大模型也兼容了这些工具格式。虽然比不上原版，但是效果同样很惊艳。

常规方式是需要 export 环境变量修改模型，对于非专业人员还是有点门槛。

最近发现 **Cheery Studio** 也提供了图形化界面管理这些 CLI 工具，对于非专业人员非常友好。推荐给大家。
